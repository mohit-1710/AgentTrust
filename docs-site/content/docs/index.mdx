title: "AgentTrust on NEAR"

AgentTrust is being built so an agent can buy a service only from the identity its owner permits, with the required capability evidence, within a bounded NEAR allowance.

The first version uses one native NEAR contract, one asset and one capability: `invoice.audit.v1`. Its demonstration is an invoice-CSV audit from two controlled providers. The agent should reject invalid supplier evidence, choose an eligible service, pay once and receive a real report.

## What each fact means

| Fact | Meaning |
|---|---|
| Registered service | A merchant published its versioned payout, signing key and endpoint commitment. |
| Valid capability credential | An owner-accepted issuer asserted a particular service version passed a named fixture suite. |
| Owner-approved service | The owner explicitly approved that exact identity for selected purchase profiles. |
| Settled payment | The native transfer succeeded and the contract callback recorded settlement. |
| Checked output | The returned report matches the requested input and the documented checks. |

These are separate facts. Registration or a credential does not grant permission to spend. A payment does not prove general service quality.

## Current build boundary

Start with the [milestone status](/reference/changelog). A controlled [r2 testnet run](/verification/live-evidence) records a deployed native core, two settled payments, contract refusals, an exact retry and a scripted MCP buyer. Native runtime captures support 20 of 21 case groups. This read-only documentation and the [website](https://www.agenttrust.tech) are live; paid providers, MCP and the model buyer remain local. The actual-model purchase, two full rehearsals, refund-gap observation and visual QA remain open. Follow [local quickstart](/getting-started/quickstart) for reproducible local checks.

Unknown services are denied. The first version has no one-off approval bypass, numeric reputation, social trust, second payment asset, escrow or hosted signer.

The website and documentation shell reuse the MIT-licensed [AgentTrust upstream baseline](https://github.com/agenttrust-labs/agenttrust/tree/21a3b111b7677d0b06ab1b063d647e4f52ea3b17). Its prior implementation and verification results are not native NEAR evidence.
