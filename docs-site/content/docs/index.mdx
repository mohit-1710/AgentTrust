AgentTrust is the non-custodial reputation firewall for AI-agent payments on Monad. It reads a payee's on-chain ERC-8004 reputation and the payer's spending policy, then allows or blocks each x402 USDC payment before it settles. ERC-8004 runs natively on Monad — agent identity (`IdentityRegistry`), reputation (`ReputationRegistry`), and capability validation (`ValidationRegistry`). AgentTrust adds a policy engine that reads the ERC-8004 reputation tier on-chain, plus a facilitator-side server that emits feedback through the ERC-8004 surface.

## The three components

**PolicyVault** is the decision engine. Five orthogonal policy kinds — `KillSwitch`, `Spending`, `Velocity`, `CounterpartyTier`, `RequireValidation` — composed under one `gate_payment` call with fail-fast semantics. The composer returns `Allow`, `Deny(reason)`, or `RequireValidation(capability_hash)`. `CounterpartyTier` reads the ERC-8004 reputation tier from the `ReputationRegistry`, with a schema-version canary that catches drift.

**x402 server** is the facilitator-side component. One authority per facilitator (`TrustGateAuthority`) signs the call into the ERC-8004 `ReputationRegistry` feedback method. `FeedbackEmissionLog` is the per-payment idempotency receipt — the `init` guard reverts on the second tx with the same `payment_id_hash`, so retries cannot double-emit. The TypeScript SDK, [`@agenttrust-sdk/trustgate`](https://www.npmjs.com/package/@agenttrust-sdk/trustgate), mounts on any Express app in five lines.

**ValidationRegistry** holds the third ERC-8004 leg. Five methods — `register_namespace`, `register_attestor`, `request_validation`, `respond_to_validation`, `revoke_validation`. The v1 sybil-resistance model is downstream-consumer filtering: PolicyVault stores a per-policy `accepted_attestors[]` array; only attestations from those keys flip the gate to `Allow`. Permissionless registration plus opinionated downstream filtering scales with the number of facilitators.

## How they compose

```
x402 facilitator (the molandak x402 facilitator)
        │
        ▼  POST /verify | /settle | /dispute
x402 server ─call─► ReputationRegistry::give_feedback
   │
   │ reads
   ▼
PolicyVault ─reads─► ReputationRegistry (ERC-8004)   ◀── reputation tier
   │
   └─reads─► ValidationAttestation
              (ValidationRegistry)
```

## x402 on Monad

The molandak x402 facilitator runs on Monad testnet at `https://x402-facilitator.molandak.org`. AgentTrust ships an x402 integration as the canonical adapter — facilitators share the same five-method `FacilitatorAdapter` contract, so adding another facilitator stays under a hundred lines. Walkthrough: [x402 facilitator adapter](/integration-guides/pay-sh-adapter).
