`@agenttrust/near-sdk` is a private workspace package in this repository. This documentation does not claim a published registry release or a ready-to-use hosted SDK service.

The implemented protocol layer contains strict wire types, canonical invoice/descriptor encoders, hashes, request hashing and Ed25519 verification. See [exports](/sdk/exports-reference).

The frozen client design adds read-only views, non-authoritative preview, local restricted-key execution, finality observation and `payService`. Those integration methods remain tracked in [milestone status](/reference/changelog); do not assume they exist merely because they are described here.

The worker client must pin the network/core, use only its local restricted key and verify the configured service/version origin. Owner management helpers run in a separate process. No arbitrary transaction signer, endpoint crawler or owner key is exposed to the agent.

Amounts and nanosecond timestamps use decimal strings. Hashes, raw invoice keys and signatures use canonical padded base64. Caller-supplied payment IDs remain stable for one purchase attempt, including process restarts.
