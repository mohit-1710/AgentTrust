`@agenttrust/near-sdk` is a private workspace package in this repository. This documentation does not claim a published registry release or a ready-to-use hosted SDK service.

The implemented protocol layer contains strict wire types, canonical invoice/descriptor encoders, hashes, request hashing and Ed25519 verification. See [exports](/sdk/exports-reference).

The implemented `AgentTrustClient` adds read-only final views, non-authoritative preview, local restricted-key execution and finality observation. `ServiceDirectory` resolves explicit service/version origins. These methods pass local tests; the [r2 testnet run](https://github.com/mohit-1710/AgentTrust/blob/main/docs/testnet-r2-evidence.md) records restricted-key execution with a scripted MCP purchase. Fresh [r3](https://github.com/mohit-1710/AgentTrust/blob/main/docs/testnet-r3-evidence.md) and [r4](https://github.com/mohit-1710/AgentTrust/blob/main/docs/testnet-r4-evidence.md) operator rehearsals separately record local-model requests through `payService` and settled native purchases. The model could request only the current host-allowed supplier; the host bound payment IDs and CSV.

The worker client pins the network/core, checks its local key's restricted permission and verifies the configured service/version origin. `AgentTrustOwner` is a separate `@agenttrust/near-sdk/owner` entrypoint for owner management; keep it in a separate process. No arbitrary transaction signer, endpoint crawler or owner key is exposed to the agent.

Amounts and nanosecond timestamps use decimal strings. Hashes, raw invoice keys and signatures use canonical padded base64. Caller-supplied payment IDs remain stable for one purchase attempt, including process restarts.
