[`@monad-agenttrust-sdk/sdk`](https://www.npmjs.com/package/@monad-agenttrust-sdk/sdk) is the TypeScript SDK for AgentTrust. It wraps the `PolicyVault` contract and the ERC-8004 `ReputationRegistry` behind a small set of viem-based helpers. Two calls do most of the work: `gate()` and `getReputation()`.

Repo: [`github.com/mohit-1710/AgentTrust`](https://github.com/mohit-1710/AgentTrust).

## Install

```bash
npm i @monad-agenttrust-sdk/sdk
# or: pnpm add @monad-agenttrust-sdk/sdk
```

The SDK depends on [viem](https://viem.sh). You pass it a viem `PublicClient` for reads and a `WalletClient` for writes.

## gate — the read-only decision

```ts
import { createPublicClient, http } from "viem";
import { gate } from "@monad-agenttrust-sdk/sdk";

const client = createPublicClient({
  transport: http("https://testnet-rpc.monad.xyz"),
});

const decision = await gate(client, {
  policyVault:  "0x34b3bB1a99377128126201359749FE7614275E37",
  payer:        "0xPayer",
  payeeAgentId: 123n,
  amount:       1_000_000n,   // 1 USDC (6 decimals)
});
// decision.kind: "Allow" | "Deny" | "RequireValidation"
```

Full reference: [gate()](/sdk/gate-payment).

## getReputation — averaged ERC-8004 score

```ts
import { getReputation } from "@monad-agenttrust-sdk/sdk";

const { count, average, decimals } = await getReputation(client, {
  reputationRegistry: "0x8004B663056A597Dffe9eCcC1965A193B7388713",
  agentId:            123n,
  clients:            ["0xTrustedAttestorA", "0xTrustedAttestorB"],
});
```

`average` is `getSummary`'s `summaryValue` — the mean score across the `clients` (trusted attestor) array, which must be non-empty.

## Configuration writes

```ts
import { createWalletClient, http } from "viem";
import { privateKeyToAccount } from "viem/accounts";
import { setPolicy, setKillSwitch } from "@monad-agenttrust-sdk/sdk";

const wallet = createWalletClient({
  account:   privateKeyToAccount(process.env.PRIVATE_KEY as `0x${string}`),
  transport: http("https://testnet-rpc.monad.xyz"),
});

await setPolicy(wallet, {
  policyVault:      "0x34b3bB1a99377128126201359749FE7614275E37",
  perTxCap:         5_000_000n,
  dailyCap:         50_000_000n,
  velocityWindow:   3_600n,
  velocityCap:      20_000_000n,
  minReputation:    70n,
  trustedAttestors: ["0xTrustedAttestorA"],
});

await setKillSwitch(wallet, {
  policyVault: "0x34b3bB1a99377128126201359749FE7614275E37",
  engaged:     true,
});
```

These map directly onto the contract calls documented in [PolicyVault](/programs/policy-vault).

## Addresses

All defaults target Monad testnet (chainId `10143`). Override any address per call. Full list: [Contract addresses](/reference/contract-addresses).
