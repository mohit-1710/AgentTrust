The SDK is a thin viem wrapper over `PolicyVault` and the ERC-8004 `ReputationRegistry`. Everything is importable from the package root.

```ts
import {
  gate,
  getReputation,
  setPolicy,
  setKillSwitch,
  recordSpend,
  TESTNET_ADDRESSES,
} from "@monad-agenttrust-sdk/sdk";
```

Source: [`github.com/mohit-1710/AgentTrust`](https://github.com/mohit-1710/AgentTrust).

## Reads

| Export | Kind | Purpose |
|---|---|---|
| `gate(client, args)` | async fn | Read-only `PolicyVault.gate` — returns the `GateDecision` union. |
| `getReputation(client, args)` | async fn | Reads `ReputationRegistry.getSummary` — returns `{ count, average, decimals }` averaged over the supplied trusted attestors. |

## Writes

| Export | Kind | Purpose |
|---|---|---|
| `setPolicy(wallet, args)` | async fn | Sets the caller's policy: caps, velocity window/cap, `minReputation`, `trustedAttestors`. |
| `setKillSwitch(wallet, args)` | async fn | Engages or releases the caller's multisig-controlled kill-switch. |
| `recordSpend(wallet, args)` | async fn | Books a settled payment against the payer's daily counter and velocity ledger. |

## Types

```ts
type GateDecision =
  | { kind: "Allow" }
  | { kind: "Deny";              reason: number; reasonName: string }
  | { kind: "RequireValidation"; capability: string };

interface GateArgs {
  policyVault:  `0x${string}`;
  payer:        `0x${string}`;
  payeeAgentId: bigint;
  amount:       bigint;
}

interface ReputationArgs {
  reputationRegistry: `0x${string}`;
  agentId:            bigint;
  clients:            `0x${string}`[];  // trusted attestors; non-empty
}
```
