---
title: gate()
description: The read-only gate call. Reads PolicyVault.gate and returns the typed decision union — Allow, Deny, or RequireValidation.
---

`gate()` calls `PolicyVault.gate` as a read-only `view` and returns the decision the contract would make. It never sends a transaction and never moves funds. Use it before settling an x402 payment to decide whether to proceed.

## Signature

```ts
import { gate } from "@monad-agenttrust-sdk/sdk";

export function gate(
  client: PublicClient,
  args: GateArgs,
): Promise<GateDecision>;
```

## `GateArgs`

```ts
interface GateArgs {
  policyVault:  `0x${string}`;   // PolicyVault address
  payer:        `0x${string}`;   // the paying account
  payeeAgentId: bigint;          // payee's ERC-8004 agent ID
  amount:       bigint;          // base units (1_000_000n = 1 USDC at 6 decimals)
}
```

## `GateDecision`

```ts
type GateDecision =
  | { kind: "Allow" }
  | { kind: "Deny";              reason: number; reasonName: string }
  | { kind: "RequireValidation"; capability: string };
```

| Decision | Next step |
|---|---|
| `Allow` | Every active check passed — settle the payment. |
| `Deny` | A check failed. Surface `reasonName` to the user; `reason` is the stable numeric code. |
| `RequireValidation` | The policy requires a capability the payee has no attestation for. Route the user through the validation flow, then re-call `gate()`. |

Reason codes: [DenyReason codes](/reference/deny-reason-codes).

## Example

```ts
import { createPublicClient, http } from "viem";
import { gate } from "@monad-agenttrust-sdk/sdk";

const client = createPublicClient({
  transport: http("https://testnet-rpc.monad.xyz"),
});

const decision = await gate(client, {
  policyVault:  "0x34b3bB1a99377128126201359749FE7614275E37",
  payer:        "0xPayer",
  payeeAgentId: 123n,
  amount:       1_000_000n,
});

switch (decision.kind) {
  case "Allow":
    console.log("gate=Allow — settle");
    break;
  case "Deny":
    console.log(`gate=Deny ${decision.reason} (${decision.reasonName})`);
    break;
  case "RequireValidation":
    console.log(`gate=RequireValidation capability=${decision.capability}`);
    break;
}
```

## How the decision is computed

`gate` runs the policy checks in order and fails fast: kill-switch, per-tx cap, daily cap, sliding-window velocity, counterparty reputation, capability validation. The reputation check reads the ERC-8004 `ReputationRegistry` via `getSummary`, averaging over the payer's trusted-attestor set. Full check order and semantics: [PolicyVault](/programs/policy-vault).
