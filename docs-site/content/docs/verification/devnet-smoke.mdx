## What the trace proves

1. **All three Solidity contracts are executable on testnet.** PolicyVault, TrustGate, and (transitively, since `reputation record` exists for the demo agent) the ERC-8004 agent-registry are reachable from off-chain code.
2. **The contract account-signed internal call works.** TrustGate's `["trustgate_auth", facilitator]` contract account signed a internal call into the ERC-8004 `give_feedback`. The resulting `reputation record` was bumped — the ERC-8004 reputation surface accepted the feedback.
3. **Idempotency holds.** The `FeedbackEmissionLog` exists on chain at the predicted contract account seeds `["feedback_log", payment_id_hash]`. A second `emit_feedback` for the same `payment_id_hash` would fail account-already-in-use; retries cannot double-emit.
4. **The atomic-tx invariant is enforced end to end on testnet.** The SDK's `composeAtomicSettleTx` produces one `Transaction` with three instructions in canonical order; both the gate-mutation and the feedback-emission committed in the same slot.

## Reproduce

From a clean checkout:

```bash
git clone https://github.com/agenttrust-labs/agenttrust && cd agenttrust
pnpm install

# 1. publish IDLs (one-time, ~0.03 MON)
forge verify-contract --chain monad-testnet \
  --filepath target/idl/trustgate.json 0x8004B663056A597Dffe9eCcC1965A193B7388713
forge verify-contract --chain monad-testnet \
  --filepath target/idl/policy_vault.json 0x34b3bB1a99377128126201359749FE7614275E37
forge verify-contract --chain monad-testnet \
  --filepath target/idl/validation_registry.json 0x8004Cb1BF31DAf7788923b405b754f57acEB4272

# 2. pre-warm 3 ERC-8004 agents (one-time, ~0.04 MON)
pnpm --filter ./examples/pay-sh-demo exec ts-node scripts/prewarm-testnet.ts

# 3. run the smoke (~0.03 MON)
pnpm --filter ./examples/pay-sh-demo exec ts-node scripts/testnet-smoke.ts
```

The full trace (signatures, contract accounts, slot numbers) lands in `examples/pay-sh-demo/testnet-smoke.json`. Re-running is idempotent — `TrustGateAuthority`, test mint, payer key, and ATAs are reused if present.

## Daily smoke (cron)

[`.github/workflows/daily-testnet-smoke.yml`](https://github.com/agenttrust-labs/agenttrust/blob/main/.github/workflows/daily-testnet-smoke.yml) runs the same flow on a 24-hour cron. The result is committed back to the repo at [`docs/proofs/smoke-2026-05-06.md`](https://github.com/agenttrust-labs/agenttrust/blob/main/docs/proofs/smoke-2026-05-06.md) (template). A failed daily smoke flips a status badge red; a green smoke means testnet, the ERC-8004 programs, and AgentTrust's three programs are all healthy.
