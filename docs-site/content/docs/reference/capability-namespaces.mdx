| Capability | Namespace field | Version field | Meaning |

| `invoice.audit.v1` | `invoice.audit` | 1 | A bounded structural invoice-CSV audit fixture suite. |

This table is a scope declaration, not a list of deployed credentials. There is no generic namespace registration or seeded multi-capability catalog in the first version.

A profile pins `conformance_suite_version` and `conformance_suite_hash` plus its accepted issuers. A credential also carries an `evidence_manifest_hash` for one validation run. The suite identity and run evidence are different commitments.

The planned report binds the exact input hash and contains logical row counts, duplicate vendor/invoice groups, rejected rows and exact per-currency totals. Valid duplicate rows remain included in those totals, which are not amounts to pay. Fixture behavior and supported CSV grammar must be documented before a conformance assertion is made.

No deployed suite hash, issuer record or credential ID is supplied here until it is backed by reviewed evidence. The build-time generator for this page is T25 work; this static native scope must not be replaced by the inherited catalog.
