---
title: DenyReason codes
description: The reasons PolicyVault.gate returns on a Deny, with what triggers each and how to fix it.
---

When `PolicyVault.gate` returns `Deny`, it carries a stable numeric reason. Clients should consume the numeric code; the name is for display.

```solidity
function gate(address payer, uint256 payeeAgentId, uint256 amount)
    external view returns (Decision decision, uint8 reason);
```

## Reasons

| Code | Name | Originating check | Triggered when | Remediation |
|---:|---|---|---|---|
| 1 | `KillSwitchEngaged` | Kill-switch | The payer's kill-switch is engaged. | Release it via `setKillSwitch(false)` (multisig). |
| 2 | `PerTxCapExceeded` | Per-tx cap | `amount > perTxCap`. | Lower the amount or raise the per-tx cap. |
| 3 | `DailyCapExceeded` | Daily cap | `spentToday + amount > dailyCap`. | Wait for the daily window to roll over, or raise the daily cap. |
| 4 | `VelocityExceeded` | Sliding-window velocity | window spend `+ amount > velocityCap` within `velocityWindow`. | Wait for the window to slide, or raise the velocity cap. |
| 5 | `ReputationBelowMin` | Counterparty reputation | the payee's averaged ERC-8004 reputation `< minReputation`. | Build the payee's reputation (more feedback from trusted attestors), lower `minReputation`, or widen the trusted-attestor set. |

A sixth outcome — `RequireValidation` — is not a `Deny`. It is returned when the policy requires a capability the payee has no attestation for. See [PolicyVault](/programs/policy-vault).

## SDK consumption

```ts
import { gate } from "@monad-agenttrust-sdk/sdk";

const decision = await gate(client, { /* … */ });

if (decision.kind === "Deny") {
  // decision.reason: number
  // decision.reasonName: string (e.g. "ReputationBelowMin")
}
```

The decision union is documented in [SDK → gate()](/sdk/gate-payment).
