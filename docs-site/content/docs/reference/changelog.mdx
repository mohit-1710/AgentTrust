The local implementation includes ordered policy gates, exact service trust/block management, reservations, dispatch, private callbacks and available-fund withdrawals. Pure tests, typechecks and WASM inspection do not establish protocol key restrictions, actual storage/refund ordering or a paid service run.

The SDK, audit engine, validator and custom HTTP/MCP purchase flow are implemented. R2 verifies a scripted controlled testnet purchase; r3 and r4 separately verify local-model requests for a host-allowed supplier, settled native payment and checked report. The read-only website and docs are live on Vercel, while paid providers, MCP and the model buyer remain local; the public decision feed shows dated on-chain decisions without running the buyer. The native refund-gap case and browser visual QA remain open. No published native package, mainnet contract deployment or general service-quality guarantee is claimed.
