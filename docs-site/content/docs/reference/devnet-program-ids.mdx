R2 ended with B's credential revoked and its identity rotated. It is evidence of that run, not a default configuration for a fresh purchase. No hosted paid-provider URL or mainnet contract deployment is claimed.

For any fresh deployment, record and verify:

| Field | Required evidence |
|---|---|
| Network/domain | RPC network and core `get_config()` agree with the client configuration. |
| Core account | Actual deployed account ID, not a display name or copied example. |
| Code | Actual deployed code hash and matching reviewed Git commit/WASM artifact. |
| Actor roles | Owner, worker session public-key fingerprint, merchants and issuer; never private keys. |
| Services | Exact service/version/payout/key/endpoint commitments plus configured origins. |
| Results | Actual transaction and receipt IDs, final state and input/output hashes. |

The core's configured domain and actual current account must match every new invoice. A successful HTTP request or explorer link alone does not prove that the correct contract enforced a purchase.

The existing mainnet guide is archived. This sprint makes no mainnet contract deployment or production custody claim.
