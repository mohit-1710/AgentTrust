---
title: "Signature domains and commitments"
description: "Separate invoice, descriptor, endpoint and request commitments."
---

| Commitment | Exact input |
|---|---|
| Invoice bytes | ASCII `AGENTTRUST_NEAR_INVOICE_V1` + zero byte + ordered invoice Borsh fields. |
| Descriptor bytes | ASCII `AGENTTRUST_NEAR_IDENTITY_V1` + zero byte + ordered descriptor Borsh fields. |
| Request hash | SHA-256 of ASCII `AGENTTRUST_INVOICE_AUDIT_REQUEST_V1` + zero byte + raw CSV UTF-8 bytes. |
| Endpoint hash | SHA-256 of the endpoint string below, including each newline. |

```text
agenttrust-http402-v1
POST
<canonical HTTPS origin>
/v1/invoice-audit
```

There is a final newline after the route. The origin uses a lowercase ASCII hostname, no userinfo/query/fragment, no trailing slash and no explicit default port. Reject cross-origin redirects. Localhost HTTP is allowed only in explicitly labeled local fixtures, not as a hosted/testnet TLS claim.

Descriptor Borsh order:

```text
schema_version:u8, network:string, core_account:AccountId,
challenge_nonce:[u8;32], service_id:AccountId, service_version:u32,
payout_account:AccountId, endpoint_hash:[u8;32], invoice_key:[u8;32],
issued_at_ns:u64, expires_at_ns:u64
```

The validator checks a fresh nonce and the registered key/identity. A descriptor's embedded key is not self-authenticating. Quote and descriptor validity defaults to 120 seconds, with a maximum 300-second lifetime and at most five seconds of issue-time skew; expiry remains strict.

The request hash is calculated before CSV parsing. Trimming an ID for duplicate detection must not alter the purchased input commitment.
