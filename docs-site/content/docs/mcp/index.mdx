The `agenttrust` MCP server lets an agent or assistant call AgentTrust directly: read a payee's ERC-8004 reputation, simulate a gate decision, register an agent, and seed feedback. It speaks the Model Context Protocol over stdio.

Repo: [`github.com/mohit-1710/AgentTrust`](https://github.com/mohit-1710/AgentTrust).

## Tools

| Tool | What it does |
|---|---|
| `get_reputation` | Reads the averaged ERC-8004 reputation for an agent over a set of trusted attestors. |
| `gate_payment` | Calls `PolicyVault.gate` and returns `Allow` / `Deny` / `RequireValidation`. |
| `register_agent` | Registers an agent in the ERC-8004 `IdentityRegistry`. |
| `seed_feedback` | Writes feedback into the ERC-8004 `ReputationRegistry` so reputation reads have data. |

`get_reputation` and `gate_payment` are read-only. `register_agent` and `seed_feedback` send transactions and require a signing key. Full I/O: [Tools](/mcp/tools).

## Add it

```bash
claude mcp add agenttrust -- npx -y @monad-agenttrust-sdk/sdk
```

Or wire it manually via `.mcp.json` — see [Install](/mcp/install).

## In use

Once added, ask your assistant:

- *"What's the reputation of agent 123, averaged over these two attestors?"* → `get_reputation`
- *"Would a 5-USDC payment from this payer to agent 123 pass the gate?"* → `gate_payment`
- *"Register a new agent for me."* → `register_agent`
- *"Seed positive feedback for agent 123."* → `seed_feedback`
