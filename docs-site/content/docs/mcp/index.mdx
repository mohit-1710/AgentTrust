> This page describes the frozen native design. Check [implementation status](/reference/changelog) before using an integration; a planned interface is not a deployed service.

The frozen MCP surface is local stdio with six tools. `pay_service` is the only money-moving tool. The other tools inspect services, policy, previews and payment state.

The worker process holds only its restricted key, pinned owner/session and network/core configuration. Owner management and issuer operations run separately. There is no hosted signer, shared full-access key or generic `sign` tool.

Service discovery is bounded to registered records and the configured version-to-origin catalog. Being listed, having a configured endpoint and passing a policy preview are different facts.

Implementation and transport verification belong to T19; see [milestone status](/reference/changelog). No native MCP package release, hosted endpoint, resource catalog or guided prompt registry is claimed by these docs.

Continue with [configuration boundary](/mcp/install) and [tool contract](/mcp/tools).
