---
title: Install
description: Add the agenttrust MCP server to Claude Code or any MCP client via claude mcp add or .mcp.json.
---

The `agenttrust` MCP server runs over stdio with `node`. Add it with one command, or by editing an `.mcp.json` config.

## Claude Code

```bash
claude mcp add agenttrust -- npx -y @monad-agenttrust-sdk/sdk
```

To pass environment (for the write tools' signing key):

```bash
claude mcp add agenttrust \
  --env RPC_URL=https://testnet-rpc.monad.xyz \
  --env PRIVATE_KEY=0xyourkey \
  -- npx -y @monad-agenttrust-sdk/sdk
```

## .mcp.json

Add an entry under `mcpServers` in your project's `.mcp.json` (or your client's MCP config):

```json
{
  "mcpServers": {
    "agenttrust": {
      "command": "npx",
      "args": ["-y", "@monad-agenttrust-sdk/sdk"],
      "env": {
        "RPC_URL": "https://testnet-rpc.monad.xyz"
      }
    }
  }
}
```

To run a local clone instead of the published package, point `command`/`args` at the built entry:

```json
{
  "command": "node",
  "args": ["/absolute/path/to/AgentTrust/mcp/dist/index.js"]
}
```

## Environment variables

| Var | Default | Effect |
|---|---|---|
| `RPC_URL` | Monad testnet RPC | The Monad RPC endpoint the server reads from. |
| `PRIVATE_KEY` | unset | Signing key for the write tools (`register_agent`, `seed_feedback`). Read tools never need it. |

The read tools (`get_reputation`, `gate_payment`) work with no key on Monad testnet (chainId `10143`). Without a key, the write tools return a clear "signer required" message.
