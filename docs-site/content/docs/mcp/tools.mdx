The `agenttrust` MCP server exposes four tools. Two are read-only and need no signing key; two send transactions and require `PRIVATE_KEY`.

## Read tools

### `get_reputation`

Reads the averaged ERC-8004 reputation for an agent over a chosen set of trusted attestors.

| Input | Type | Notes |
|---|---|---|
| `agent_id` | integer | The payee's ERC-8004 agent ID. |
| `clients` | string[] | Trusted attestor addresses to average over. Must be non-empty. |

Returns `{ count, average, decimals }` — `average` is `getSummary`'s `summaryValue` (the mean score across `clients`).

### `gate_payment`

Calls `PolicyVault.gate` and returns the decision.

| Input | Type | Notes |
|---|---|---|
| `payer` | string | The paying account. |
| `payee_agent_id` | integer | The payee's ERC-8004 agent ID. |
| `amount` | string | Base units (e.g. `"1000000"` = 1 USDC). |

Returns one of `Allow`, `Deny` (with the reason), or `RequireValidation` (with the required capability). Reason codes: [DenyReason codes](/reference/deny-reason-codes).

## Write tools (require a signer)

### `register_agent`

Registers an agent in the ERC-8004 `IdentityRegistry`.

| Input | Type | Notes |
|---|---|---|
| `metadata_uri` | string | Off-chain metadata URI for the agent. |

Returns the new agent ID and the transaction hash with a Monad Explorer URL.

### `seed_feedback`

Writes feedback into the ERC-8004 `ReputationRegistry` so reputation reads have data to average. Useful for setting up a demo or bootstrapping a fresh agent's score.

| Input | Type | Notes |
|---|---|---|
| `agent_id` | integer | The agent receiving feedback. |
| `score` | integer | The feedback score. |

Returns the transaction hash with a Monad Explorer URL.
