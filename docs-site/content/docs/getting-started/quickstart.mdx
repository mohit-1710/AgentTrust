Everything below runs against Monad testnet (chainId `10143`). You need a funded testnet key only for the optional on-chain configuration step — reading reputation and simulating a gate decision are read-only.

## 1. Install the SDK

```bash
npm i @monad-agenttrust-sdk/sdk
# or: pnpm add @monad-agenttrust-sdk/sdk
```

The SDK is built on [viem](https://viem.sh). It needs the Monad testnet RPC and the deployed `PolicyVault` address (both defaulted for testnet).

## 2. Gate a payment

`gate()` is a read-only call into `PolicyVault.gate`. It returns the decision the contract would make for a given payer, payee agent, and amount.

```ts
import { createPublicClient, http } from "viem";
import { gate } from "@monad-agenttrust-sdk/sdk";

const client = createPublicClient({
  transport: http("https://testnet-rpc.monad.xyz"),
});

const decision = await gate(client, {
  policyVault:   "0x34b3bB1a99377128126201359749FE7614275E37",
  payer:         "0xYourPayerAddress",
  payeeAgentId:  123n,                 // the payee's ERC-8004 agent ID
  amount:        1_000_000n,           // 1 USDC (6 decimals)
});

switch (decision.kind) {
  case "Allow":             /* settle the payment */ break;
  case "Deny":              console.log("denied:", decision.reason); break;
  case "RequireValidation": console.log("needs capability:", decision.capability); break;
}
```

`Allow` means every active check passed. `Deny` carries the failing reason ([DenyReason codes](/reference/deny-reason-codes)). `RequireValidation` means the policy requires a capability attestation the payee does not yet have.

## 3. Read an ERC-8004 reputation score

`getReputation()` reads the payee's averaged reputation from the ERC-8004 `ReputationRegistry`. You supply the agent ID and the set of trusted attestors (`clients`) whose feedback you want averaged — the array must be non-empty.

```ts
import { getReputation } from "@monad-agenttrust-sdk/sdk";

const { count, average, decimals } = await getReputation(client, {
  reputationRegistry: "0x8004B663056A597Dffe9eCcC1965A193B7388713",
  agentId:            123n,
  clients:            ["0xTrustedAttestorA", "0xTrustedAttestorB"],
});

console.log(`avg score ${average} over ${count} feedback entries (${decimals} decimals)`);
```

There is no global reputation: `average` is computed only over the attestor set you chose to trust. This is the same read `PolicyVault.gate` performs for its counterparty-reputation check.

## Optional — configure a policy on chain

To change what `gate` decides, a payer sets their policy with a funded testnet key:

```ts
import { createWalletClient, http } from "viem";
import { privateKeyToAccount } from "viem/accounts";
import { setPolicy } from "@monad-agenttrust-sdk/sdk";

const wallet = createWalletClient({
  account:   privateKeyToAccount(process.env.PRIVATE_KEY as `0x${string}`),
  transport: http("https://testnet-rpc.monad.xyz"),
});

await setPolicy(wallet, {
  policyVault:        "0x34b3bB1a99377128126201359749FE7614275E37",
  perTxCap:           5_000_000n,        // 5 USDC
  dailyCap:           50_000_000n,       // 50 USDC
  velocityWindow:     3_600n,            // seconds
  velocityCap:        20_000_000n,       // 20 USDC per window
  minReputation:      70n,
  trustedAttestors:   ["0xTrustedAttestorA"],
});
```

See [PolicyVault](/programs/policy-vault) for the full set of configuration calls (`setPolicy`, `setKillSwitch`, `recordSpend`).
