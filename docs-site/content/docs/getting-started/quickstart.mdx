Use a checkout of `mohit-1710/AgentTrust`; access requires authorization while the repository is private. The paid MCP and providers run locally. There is no published native package or public payment endpoint.

## Pin the tools

Use Node **24.22.2**, pnpm **10.33.0**, Rust **1.97.1** with `wasm32-unknown-unknown`, and an OpenSSL CLI supporting `req -addext` for the local TLS tests. The root toolchain files and lockfiles are the source of truth. `scripts/env.sh` uses installed tools or the local ignored tool directory; it does not install tools itself.

From the repository root:

```sh
. scripts/env.sh
pnpm install --frozen-lockfile --ignore-scripts
pnpm check:fast
pnpm build:contract
pnpm test:mcp:stdio
```

`check:fast` runs pure Rust tests, TypeScript tests and native typechecking. `build:contract` compiles WASM and inspects its NEAR host imports without executing it. `test:mcp:stdio` builds the local MCP server and calls all six tools against loopback mock RPC without a worker key; its ignored transcript is mock-only. These commands send no transaction or native payment.

## Build the preserved surfaces

```sh
pnpm build:surfaces
```

This explicitly generates native docs blocks and the Fumadocs collection, checks the active corpus, then builds the website and docs. Install and pre/post lifecycle scripts stay disabled. A surface build proves compilation, not deployment, visual acceptance or current website claims.

## Before a purchase can run

The owner must fund spendable principal and separate storage credit, configure a policy/profile, explicitly trust the intended service version, register a session and install its restricted protocol key. Merchants and issuers need their own funded storage accounts. These roles must not share the worker process's key material.

The testnet setup/capture commands and bounded buyer are implemented with explicit execution flags. The [r2 testnet qualification](/verification/testnet-r2) used a scripted MCP buyer; fresh [r3](/verification/testnet-r3) and [r4](/verification/testnet-r4) records each show a local Ollama model requesting host-allowed B, a settled 0.002 NEAR purchase, direct refusals and an exact retry. [Native runtime evidence](https://github.com/mohit-1710/AgentTrust/blob/main/docs/native-runtime-evidence.md) supports 20 of 21 groups; the refund-gap case remains open. Follow the [testnet runbook](https://github.com/mohit-1710/AgentTrust/blob/main/docs/testnet-demo-runbook.md) and [buyer runbook](https://github.com/mohit-1710/AgentTrust/blob/main/examples/buyer-agent/README.md) for prerequisites and role separation. The local commands above do not execute a transaction or perform browser visual QA.

The standing execution rules keep database-writing Sandbox work user-run. Read the [runtime runbook](https://github.com/mohit-1710/AgentTrust/blob/main/docs/runtime-runbook.md) and its open coverage gaps; no runtime, funding or deployment command is part of the local commands above.
