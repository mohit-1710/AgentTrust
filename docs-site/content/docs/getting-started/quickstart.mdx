Use an authorized checkout of `mohit-1710/AgentTrust`. The repository is private during preparation. There is no published native package or public payment endpoint to install from this snapshot.

## Pin the tools

Use Node **24.22.2**, pnpm **10.33.0** and Rust **1.97.1** with `wasm32-unknown-unknown`. The root toolchain files and lockfiles are the source of truth. `scripts/env.sh` uses installed tools or the local ignored tool directory; it does not install tools itself.

From the repository root:

```sh
. scripts/env.sh
pnpm install --frozen-lockfile --ignore-scripts
pnpm check:fast
pnpm build:contract
```

`check:fast` runs pure Rust tests, TypeScript tests and native typechecking. `build:contract` compiles WASM and inspects its NEAR host imports without executing it. A successful build is not a native payment or runtime proof.

## Before a purchase can run

The owner must fund spendable principal and separate storage credit, configure a policy/profile, explicitly trust the intended service version, register a session and install its restricted protocol key. Merchants and issuers need their own funded storage accounts. These roles must not share the worker process's key material.

Runtime preparation, actual testnet setup, live purchases and hosted surfaces remain separate gates. At this snapshot, root commands for those unfinished tasks fail explicitly with a not-ready message. Do not substitute a passing unit test for a missing runtime result.

The standing execution rules keep database-writing Sandbox work user-run. Follow the reviewed runbook when it is available; no runtime, funding or deployment command is part of the local commands above.

Continue with [owner/session authority](/programs/policy-vault), [testnet configuration](/reference/devnet-program-ids) and [verification lanes](/verification).
