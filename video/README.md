## Rebuild the editorial cut

From the repository root, with `ffmpeg`, `ffprobe`, `uv` and the demo-video skill available:

```sh
uv venv --python 3.12 video/work/venv
uv pip install --python video/work/venv/bin/python kokoro-onnx==0.6.1 soundfile==0.14.0 pillow==13.0.0
curl --fail --location --output video/work/kokoro-v1.0.onnx https://github.com/thewh1teagle/kokoro-onnx/releases/download/model-files-v1.1/kokoro-v1.0.onnx
curl --fail --location --output video/work/voices-v1.0.bin https://github.com/thewh1teagle/kokoro-onnx/releases/download/model-files-v1.1/voices-v1.0.bin
shasum -a 256 video/work/kokoro-v1.0.onnx video/work/voices-v1.0.bin
video/work/venv/bin/python video/make_voice_editorial.py
uv run /Users/mohit/.agents/skills/demo-video/scripts/transcribe.py video/voice/editorial-narration.wav --out video/work/editorial-whisper --trim 0
uv run /Users/mohit/.agents/skills/demo-video/scripts/plan_lines.py --script video/script.txt --whisper video/work/editorial-whisper --out video/work/editorial-alignment
cp video/work/editorial-alignment/captions.json video/work/editorial-captions.json
video/work/venv/bin/python video/render_editorial.py --stills-only
video/work/venv/bin/python video/render_editorial.py
video/work/venv/bin/python video/make_cover_editorial.py
```

## Final checks

The demo-video skill check passed full decode, 1920×1080 at 30 fps, H.264 High/yuv420p, AAC 48 kHz stereo, faststart, zero clipped samples and 50 captions in one fixed bottom position without short or overlapping captions. Integrated voice level measured −16.5 LUFS and −4.4 dBTP. Its speech matcher recognized 48/50 written caption chunks verbatim; the two exceptions write code identifiers (`invoice.audit.v1` and `execute_payment`) where the narration says those terms in words. The cover was inspected at full size and phone thumbnail size. Independent first-time and technical reviewers inspected the exported frames and evidence boundaries. The first-time review's site-pacing concern was addressed with the guided site crop and retimed worker-key magnifier; the final targeted recheck closed it. Human listening remains part of the handoff.
